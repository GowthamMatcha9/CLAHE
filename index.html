How this widget works
  • Tile grid: divides the image into local regions.
  • Clip limit: limits tall histogram bins and controls excessive contrast/noise amplification.
  • Input intensity range: CLAHE is applied only to intensities in this range; values outside it are unchanged.
  • Colour images: the default luminance mode enhances brightness/contrast while preserving colour relationships.
